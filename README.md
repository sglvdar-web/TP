# Система управления рецептами
Приложение предназначено для хранения и обработки рецептов. Позволяет работать с ингредиентами, автоматически формировать список покупок, объединять одинаковые продукты и изменять количество ингредиентов в зависимости от требуемого числа порций.
## Установка

git clone https://github.com/sglvdar-web/TP.git
cd TP
pip install -r
requirements.txt

## Использование
Запуск тестов:

pytest
